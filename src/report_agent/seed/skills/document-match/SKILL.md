# 业务单据核对

## 适用场景

任何要从单据中取值的模板，在取值之前先做这一步。客户可能同时办理过多项业务，上游有时会把其它业务的单据一起传进来。

## 判断方法

1. 入参中没有业务名称时，视为单据属于本次业务。
2. 否则用 `text_contains(target=业务名称, normalize=true, extraChars=" \n")` 在单据全文中查找
   （平台对两边做同样的清洗：Unicode 兼容归一化，去掉中英文标点、空格和换行）。
3. 包含 → 单据属于本次业务，可以作为取值来源。
4. 不包含 → 单据**不属于**本次业务：
   - 所有“只能来自单据”的字段都按“找不到”提交，不要从这份单据中取值；
   - 字段说明中允许从订购短信取值的（例如标准资费），改从订购短信中取。
5. 上游没有提供单据时，所有只能来自单据的字段按“找不到”提交。

## 提交要求

从单据取值的字段，证据引用单据原文片段（`{"type":"document","quote":"..."}`），值与片段中的文字完全一致。
如果判断单据不属于本次业务，在相关字段的 reasoning 中写明“单据未命中业务名称”。
