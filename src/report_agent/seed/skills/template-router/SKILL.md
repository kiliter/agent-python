# 模板路由（聊天窗口选模板指南）

本 Skill 专供嵌入式聊天路由 Agent 在推荐申告报告模板时加载，不关联任何外部网关接口，也不绑定到任何填报模板。请严格结合当前会话的**上层/用户补充入参（`inputs`）**、**单据文本（`document`）**与**客户诉求描述**，从在线模板中筛选最贴合的模板（最多推荐 3 个）。

---

## 路由判定总则

### （一）入参与单据联合研判流程

1. **优先检查强特征专属入参**：
   - 传入 `充值号码`、`充值时间`（或 `extraInfo` 中包含 `充值号码`）：直接锁定**充值族（106、107）**。
   - 传入 `账单`（格式如 `202610$202610`）：优先指向 **119 套餐费用争议类**（全库唯一支持按 `账单` 展开跨月账期提醒短信并输出账单总费用/争议费用/套外扣费明细的模板）。
   - 传入 `deadlineDate`（到期截止日期）：重点排查挂载到期或续约提醒的 5 个模板（**105、108、112、120、129**）。
   - 传入 `extraInfo` 含 `安装地址`：关注 **121 宽带业务费用争议类**；含手机号且涉及携转：关注 **122 携号转网协议冲突类**。
2. **结合 `业务名称` 与 `document` 单据识别业务形态**：
   - **账单 / 流量详单**：出现“账期”“总费用”“争议费用”“套餐外流量/语音”“达量降速/限速阈值”等，优先看 **119、124、125**。
   - **充值缴费记录**：出现充值订单号、支付方式、到账状态、充错号码，看 **106、107**。
   - **靓号使用协议 / 过户申请**：出现“靓号等级”“《靓号使用协议》”“最低消费/保底”“过户”，看 **131、132**。
   - **携号转网记录**：出现“携号转网”“携转资格”“授权码”，看 **122**。
   - **宽带受理单**：出现“宽带开户”“安装地址”“光猫/机顶盒设备押金”“宽带包年续约”，看 **120、121**。
   - **终端捆绑 / 机卡匹配协议**：单据包含“终端信息”“终端型号”“设备串号”“机卡匹配要求”或客户因机卡分离/停机违约，优先看 **115**。
   - **增值业务 / 会员权益**：如视频彩铃、咪咕会员、云盘、来电显示、电视端/合作方平台/APP 订购扣费，优先看 **116**。
3. **锚定客户核心争议焦点**：
   - **不认可办理本身**：不知情（**100**）、非本人未授权（**104**）、办理未告知资费（**103**）、营销话术误导（**130**）、宣传与实际不符（**126**）、质疑办理合规与公示（**102**）、一般业务/活动办理核查（**101、123、128**）。
   - **认可办理但对履约、变更、解约或到期计费有异议**：承诺赠费/权益未兑现（**127**）、套餐已变更为新套餐需查原套餐（**118**）、想降档或改套餐被合约拦住（**117、111**）、想取消业务或提前解约嫌违约金高（**110、113、114**）、仅质疑合约协议条款（**109**）、合约自动顺延/续约争议（**112**）、优惠/合约/营销活动到期恢复原价或扣费（**105、108、129**）。

### （二）相近模板族精准区分规则

- **业务办理族（100 / 101 / 102 / 103 / 104 / 123）**：
  - **100（不知情）** vs **104（未授权）**：客户称“完全不知道有这个业务/没办过”选 **100**；明确称“未经本人同意、他人代办、非本人操作未授权”选 **104**。
  - **103（告知争议）**：仅针对普通业务/套餐的标准资费告知争议（无营销活动三要素段落），按渠道举证受理单标注、录音时间段告知或办理页面标注。
  - **102（合规类）** vs **101（争议类）**：两者均支持“业务”与“营销活动”双分支；若工单强调核查业务合规性、资费公示或下架知识库证明选 **102**，普通业务办理争议兜底选 **101**。
  - **123（活动办理争议）**：明确是营销活动（固定输出活动时间、活动内容、违约责任三要素，无普通套餐分支，也不含公示尾段）。
- **合约解约与违约金族（108 ~ 115）**：
  - **108（合约到期处理）** vs **112（合约延续争议）**：**108** 用于合约期满后未取消导致恢复原价/自动关闭（查单日到期提醒 `reminder-sms`）；**112** 用于合约到期**自动续约/顺延**争议（查 `renewal-reminder-sms` 区分“到期延续/到期结束”及“续约成功提醒”，并核查续约条款与续约期限）。
  - **109（合约协议争议）**：仅核查合约协议条款与办理合规，不输出提前解约违约金结论。
  - **110（合约及违约金）** vs **113（合约期内取消违约金）** vs **114（合约活动提前解约）** vs **111（合约套餐提前解约）**：
    - 客户在合约期内想**改套餐/套餐解约**受阻选 **111**（有违约责任守卫，输出“办理套餐变更需支付违约金”）；
    - 客户要求**取消某项合约内业务**被收违约金选 **113**；
    - 客户要求**提前解约/中断合约活动**且单据需按违约条款有条件判定时选 **114**，综合质疑合约绑定与违约金选 **110**。
  - **115（合约活动违约）**：客户因**机卡分离、停机、终端串号不匹配等违约行为**无法享受活动优惠（唯一含 `机卡匹配要求`、`终端型号`、`设备串号`、`违约行为`、`违约时间` 的模板）。
- **套餐变更与资费族（117 / 118 / 119）**：
  - **117（套餐变更与降档）**：套餐**尚未变更**，客户想降档/变更套餐但因活动未到期需先付违约金中断活动。
  - **118（套餐变更争议）**：套餐**已经变更**，客户对变更过程有异议，需通过退订提醒短信还原变更前的 `原套餐名称`。
  - **119（套餐费用争议）**：针对月度账单总金额、争议金额、套餐外超额费用及账期内到期/语音超额/流量超额提醒短信的全景核查。
- **充值族（106 / 107）**：
  - 正常充值未到账、延迟到账、金额核对选 **106**；把话费**充错到他人号码**选 **107**。
- **宽带族（120 / 121）**：
  - 宽带到期**自动续约、履行次数、光猫/机顶盒设备押金退还**争议选 **120**；宽带**开户装机、安装地址、宽带套餐/活动费用**争议选 **121**。
- **流量族（124 / 125）**：
  - 投诉流量跑得快、高速流量用尽后**网速变慢/触发达量限速**选 **124**；投诉超出套餐流量（含国内流量、定向流量）产生**套外流量扣费**选 **125**。
- **营销宣传与到期族（105 / 126 / 127 / 128 / 129 / 130）**：
  - **105（优惠活动到期资费恢复）** vs **129（营销活动到期费用争议）**：均查 `reminder-sms` 到期提醒；明确投诉优惠折扣期满**恢复套餐原价**选 **105**，泛指营销案到期后费用变动（恢复原价或自动关闭）选 **129**。
  - **126（营销宣传不符）**：需比对掌厅页面条款、热线录音（含 `沟通日期`、`时间段`）或受理单标注与宣传是否一致。
  - **127（营销承诺不兑现）**：承诺的返话费、赠款、权益礼品未兑现。
  - **130（营销活动误导办理）**：投诉推销过程话术误导、隐瞒限制条件诱导办理。
  - **128（营销活动争议）**：营销活动常规争议兜底（含网厅掌厅公示说明）。
- **专项业务族（116 / 122 / 131 / 132）**：
  - 增值业务/SP/会员权益扣费选 **116**；携号转网受协议限制及携转短信核查选 **122**；号码**过户受阻**（无论靓号还是普通号，模板内自带靓号/非靓号双分支）一律选 **131**；不涉及过户的纯**靓号保底/协议期/等级**争议选 **132**。

### （三）置信度分级与推荐数量要求

- **推荐数量**：每次最多推荐 **3 个**在线模板，按匹配度从高到低排列；切勿推荐已下线或不存在的模板 ID。
- **置信度（`level`）标准**：
  - **高**：客户诉求、单据类型与入参特征完全吻合某一细分模板，边界清晰无歧义（通常首选为“高”，如有 1 个强相关备选可列为“中”）。
  - **中**：能锁定争议大类（如合约违约金族、业务办理族或到期费用族），但现有单据与入参未指明具体子场景（例如仅有活动受理单而无客户原话），可推荐同族最核心的 2~3 个模板并说明适用差异。
  - **低**：单据为空或信息极少、入参仅有手机号或模糊名称，只能提供通用兜底候选，需在回复中引导用户补充争议焦点或缺失入参。

## 在线模板适用清单（100~132）

### 100 不知情业务办理争议处理类
- **适用场景**：客户反映对名下已开通的普通业务/套餐或营销活动完全不知情，否认曾主动办理。模板自动按 `争议类型` 区分“业务”（标准资费+套餐内容）与“营销活动”（活动时间+活动内容+违约责任），并举证二次确认短信、验证码短信及办理成功告知短信。
- **典型特征/关键词**：不知情定制、没办过、莫名开通、乱扣费不知情、二次确认短信、验证码回填、成功办理告知短信。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：强调“客户声称不知情”；若客户明确强调“非本人操作/未经授权/他人代办”优先选 **104**；若承认办理但称“未告知资费”选 **103**；若为视频彩铃/会员等增值业务优先考虑 **116**。

### 101 业务办理争议类
- **适用场景**：客户对已办理的普通业务、套餐或营销活动产生一般性办理争议（无不知情、未授权、未告知、误导等特定定性标签时的通用业务办理核查模板）。
- **典型特征/关键词**：业务办理争议、套餐办理核查、活动办理核实、办理协议、鉴权方式、办理成功告知短信。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：与 **100 / 102 / 104** 字段相同，**101** 是业务办理族的通用基准模板；若需附加网厅和掌厅资费公示及下架知识库说明选 **102**；若纯属营销活动且无需普通套餐分支可选 **123 / 128**。

### 102 业务办理合规类
- **适用场景**：客户或监管工单质疑业务/营销活动办理流程的合规性、鉴权有效性以及产品资费是否公开透明公示。在完整核查办理协议、录音、确认短信与告知短信外，额外声明产品已通过网厅和掌厅公示。
- **典型特征/关键词**：合规性核查、办理流程不规范、违规办理、资费公示、下架知识库截图、鉴权合规。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：比 **100 / 101 / 104** 多了末尾“产品已通过网厅和掌厅进行公示（资费公示、下架知识库截图）”合规举证段落。

### 103 业务办理告知争议类
- **适用场景**：客户认可办理过普通业务或套餐，但投诉办理时工作人员或页面未明确告知标准资费或具体业务内容。
- **典型特征/关键词**：未告知资费、没说清楚收费标准、未履行告知义务、受理单标注、电话录音告知、宣传页面标注。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：不含营销活动三要素分支，仅核查普通业务/套餐 `标准资费`，并在报告末尾按热线/掌厅/其他渠道专门输出受理单标注、电话录音时间段告知或办理页面标注的告知证据；若涉及营销活动宣传与录音时间段核对则选 **126**。

### 104 业务办理未授权争议处理类
- **适用场景**：客户投诉业务、套餐或营销活动未经本人授权同意即被开通（如质疑营业厅/热线擅自操作、他人冒办代办、未通过本人身份鉴权或二次确认）。
- **典型特征/关键词**：未授权、未经本人同意、非本人办理、擅自开通、代办争议、私自订购。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：聚焦“未获本人授权/非本人意愿”；若客户仅表示“不知道什么时候有的”选 **100**；若投诉被推销话术忽悠而本人点了确认则选 **130**。

### 105 优惠活动到期资费恢复争议处理模板
- **适用场景**：客户办理的阶段性折扣/减免优惠活动期满后，因未申请取消或未办理变更，套餐按协议恢复原价引发的涨价争议。支持查询活动到期前下发的到期提醒短信（`reminder-sms`）。
- **典型特征/关键词**：优惠到期、恢复原价、折扣期满涨价、减免结束、到期提醒短信、未申请取消。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`、`deadlineDate`（可选，活动到期截止日期）。
- **与相近模板的区分点**：正文明确落脚于“套餐恢复原价”；若泛指营销活动到期后费用争议（恢复原价或自动关闭）对比 **129**；若强调合约期满处理对比 **108**；若涉及自动续约延续一轮周期则选 **112**。

### 106 充值争议处理通用模板
- **适用场景**：客户对手机话费充值记录、未到账、延迟到账、充值金额或充值渠道产生疑问，需调取余额流水接口（`qry-balance`）逐笔核实充值时间、支付方式、充值金额与订单流水号。
- **典型特征/关键词**：话费充值、充值未到账、延迟到账、缴费记录、充值流水、订单号、银行通道维护。
- **关键入参**：`手机号码`、`充值号码`、`充值时间`（支持 `yyyyMMdd`、`yyyyMM` 或日期区间）、`extraInfo`（可选 JSON，含充值号码等）。
- **与相近模板的区分点**：用于给正确号码充值的通用到账与流水核查；若客户明确表示“把话费充错到别的手机号了”，必须选 **107**。

### 107 充值错号处理类
- **适用场景**：客户在充值缴费时输错手机号码，将话费误充入他人号码并引发退费或核查诉求，需查询被充错目标号码在指定账期/日期内的真实充值流水。
- **典型特征/关键词**：充错号、误充他人号码、输错手机号充值、错充退费、充值缴费记录。
- **关键入参**：`手机号码`、`充值号码`、`充值时间`、`extraInfo`（优先取其中的充值号码或单据中的 11 位被充值号码）。
- **与相近模板的区分点**：专用于“充错号码”场景（`客户号码` 支持回退从单据提取被充值的 11 位号码）；非错号的一般充值未到账/延迟到账选 **106**。

### 108 合约到期处理类
- **适用场景**：客户办理的合约类活动已到期，对到期前是否收到提醒、到期后套餐恢复原价或自动关闭的处理结果有异议，需通过 `reminder-sms` 核查到期提醒短信与日期。
- **典型特征/关键词**：合约到期、协议期满、到期提醒短信、恢复原价、套餐自动关闭。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`、`deadlineDate`（可选，合约到期截止日）。
- **与相近模板的区分点**：针对**合约已到期**且按约恢复原价/关闭；若合约到期触发了**自动顺延/续约**争议必须选 **112**；若合约**尚未到期**要求提前解约选 **110 / 111 / 113 / 114**。

### 109 合约协议争议类
- **适用场景**：客户对所签署合约协议本身的条款内容（活动期限、优惠规则、客户承诺/违约责任条款等）存在异议或要求核实协议详情，暂不涉及提前解约赔付违约金计算或到期提醒。
- **典型特征/关键词**：合约协议争议、协议内容核查、不认可协议条款、合约期查询、办理协议。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：纯协议条款与办理过程核查，正文**不含**“提前中断需支付违约金”结论句；只要争议焦点包含提前解约收违约金，应优先选 **110 / 111 / 113 / 114**。

### 110 合约及违约金争议处理类
- **适用场景**：客户对名下未到期合约约束以及提前终止合约需按协议支付违约金的规定一并提出异议，属于合约绑定+违约金争议的综合处理模板。
- **典型特征/关键词**：合约及违约金、违约金过高、不认可违约金、合约绑定限制、提前中断支付违约金。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：固定输出“如需提前中断活动，需按协议违约条款支付违约金后办理”；若客户具体诉求是“取消该业务被收违约金”更贴合 **113**，若是“改套餐/降档被合约拦住”选 **111** 或 **117**，若是客户发生机卡分离等违约行为选 **115**。

### 111 合约套餐提前解约处理类
- **适用场景**：客户在合约套餐协议期未满时申请解约以办理套餐变更，系统根据单据是否存在违约责任条款说明“如需办理套餐变更，需按协议违约条款支付违约金中断活动后办理”。
- **典型特征/关键词**：合约套餐解约、提前解除套餐合约、合约期改套餐受阻、中断活动办理套餐变更。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：侧重**合约套餐解约以变更套餐**（且带 `违约责任` 非空守卫）；若侧重套餐降档诉求可同步参考 **117**；若单纯提前解约营销活动不涉及改套餐则选 **114**。

### 112 合约延续争议类
- **适用场景**：客户投诉合约或优惠活动到期后被“自动续约/自动顺延”，或对到期延续/到期结束短信告知有争议。唯一调用 `renewal-reminder-sms` 核查到期前 ±31 天窗口内的【续约确认提醒】/【到期提醒】及【续约成功提醒】短信。
- **典型特征/关键词**：自动续约、合约自动延续、顺延一年、续约条款、续约确认提醒、续约成功提醒、到期结束提醒。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`、`deadlineDate`（可选，到期基准日）。
- **与相近模板的区分点**：全库唯一处理移动合约**自动续约/顺延双分支（到期延续 vs 到期结束）**的模板；宽带业务的续约与押金争议请选 **120**；到期不续约而是恢复原价请选 **105 / 108 / 129**。

### 113 合约期内业务取消违约金争议类
- **适用场景**：客户在合约期内明确要求退订、取消正在履行的合约活动或捆绑业务，因被告知未到期取消需赔付违约金而产生投诉。
- **典型特征/关键词**：合约期内取消业务、退订活动收违约金、无法直接取消、强制消费期取消赔偿。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：核心动作是客户要求**取消/退订业务**触发违约金；若泛指合约及违约金争议对比 **110**，若强调提前解除合约活动且视单据是否有违约责任动态展示违约金结论对比 **114**。

### 114 合约活动提前解约类
- **适用场景**：客户在合约营销活动尚未到期时要求提前解约中断活动，模板核查办理详情与公示情况，并在单据包含违约责任条款时输出提前中断需支付违约金说明。
- **典型特征/关键词**：活动提前解约、提前终止合约活动、解除营销案绑定、合约未到期解约。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：针对**合约营销活动提前解约**（带 `违约责任` 条件分支）；若对象为合约套餐且目的是变更套餐选 **111**；若客户因自身违约（如机卡分离）被停优惠选 **115**。

### 115 合约活动违约争议处理模板
- **适用场景**：客户办理购机补贴、终端捆绑或机卡匹配类合约活动后，在活动期内发生机卡分离、停机、拆机等违约行为，导致无法继续享受优惠或产生违约追偿争议。
- **典型特征/关键词**：机卡分离、机卡匹配要求、终端信息、捆绑终端型号、设备串号（IMEI）、违约行为、违约时间、无法享受活动优惠。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：全库唯一提取 `机卡匹配要求`、`终端型号`、`设备串号` 以及客户具体 `违约行为` 和 `违约时间` 的模板；只要单据含“终端信息”或争议源于客户履约违约导致优惠失效，首选 **115**。

### 116 增值业务扣费争议处理模板
- **适用场景**：客户对视频彩铃、咪咕视频/音乐会员、云盘、来电显示、手机报、权益包等增值业务（含热线、合作方平台、电视端、APP、短信渠道办理）的订购与月功能费扣费产生争议。
- **典型特征/关键词**：增值业务扣费、功能费争议、会员包扣费、视频彩铃、合作方平台、电视端点播、APP订购验证码。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：专用于**增值业务/会员权益/SP 类小额或功能包扣费**；若争议对象为主资费套餐或常规合约活动，选 **100 / 101 / 119**。

### 117 套餐变更与降档争议处理类
- **适用场景**：客户申请将高档位套餐降档为低档位套餐或变更为其他主套餐时，因名下存在未到期的合约或营销活动而无法直接办理，需先支付违约金中断活动。
- **典型特征/关键词**：套餐降档受阻、不让改低价套餐、变更套餐限制、降档违约金、保底消费期内改套餐。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：套餐**尚未变更成功**，诉求是“想降档/改套餐受阻”（与 **111** 近似，客户明确提“降档”时首选 **117**）；若套餐**已经变更完毕**而客户质疑为何把原套餐改掉了，必须选 **118**。

### 118 套餐变更争议类
- **适用场景**：客户的手机套餐已经从旧套餐变更为新套餐，客户对套餐变更过程、受理鉴权或原套餐退订情况存在异议。唯一调用 `original-package-name` 从同日退订提醒短信中提取变更前的 `原套餐名称`。
- **典型特征/关键词**：套餐被更改、原套餐名称、旧套餐变更为新套餐、退订提醒短信、改回原套餐。
- **关键入参**：`手机号码`、`业务名称`（新变更的目标套餐名）、`创建时间`、`业务月份`。
- **与相近模板的区分点**：全库唯一还原“将套餐由`原套餐名称`变更为`商品名称`”的模板；若涉及月账单费用明细与超套扣费选 **119**；若是申请降档受阻选 **117**。

### 119 套餐费用争议类
- **适用场景**：客户对某账期或多账期的话费账单总额、套餐月租、活动到期资费恢复及套餐外流量/语音/短彩信超额扣费提出综合异议。调用 `billing-cycle-sms` 核查账期内活动到期资费变更提醒、语音超额提醒与流量超额提醒记录。
- **典型特征/关键词**：账单争议、月租乱扣费、总费用与争议费用、计费周期、套餐外上网/通话超额扣费、语音超额提醒、流量超额提醒。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`、`账单`（账单起止月份 `yyyyMM$yyyyMM`，如 `202610$202610`）。
- **与相近模板的区分点**：唯一包含 `<QueryBillNew>` 账单明细与跨月 `账期短信提醒列表` 的重型综合账单模板；若单纯查流量超套且无 `账单` 区间入参、仅聚焦国内流量+定向流量计费规则选 **125**。

### 120 宽带业务续约争议类
- **适用场景**：客户对家庭宽带/融合宽带包年或合约活动到期后的自动续约、到期前提醒短信、已续约次数及光猫/机顶盒等宽带设备押金退还情况产生争议。
- **典型特征/关键词**：宽带续约、宽带包年自动延续、宽带到期提醒、光猫押金、机顶盒设备押金、押金退还记录。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`、`deadlineDate`（可选，宽带活动到期日）。
- **与相近模板的区分点**：针对宽带**续约与设备押金记录**（含 `有设备押金` 分支及 `reminder-sms`）；若为宽带新装开户、安装地址核实或日常宽带月费争议则选 **121**。

### 121 宽带业务费用争议类
- **适用场景**：客户对宽带开户办理、宽带套餐资费、宽带捆绑营销活动费用或安装地址记录产生争议，支持从单据或 `extraInfo` 提取宽带安装地址与客户手机号。
- **典型特征/关键词**：宽带扣费、宽带开户、宽带套餐名称、安装地址、家宽资费争议、融合宽带活动。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`、`extraInfo`（可选，含手机号、安装地址等）。
- **与相近模板的区分点**：聚焦**宽带开户、安装地址与费用核查**；若争议核心为宽带到期自动续约或设备押金退还，应选 **120**。

### 122 携号转网协议冲突类
- **适用场景**：客户申请携号转网（携出）时因名下存在未到期的合约、优惠活动或业务协议受阻，或客户发送携转查询短信后对我公司回复的限制条件有异议。唯一调用 `number-portability-sms` 提取携转资格查询日期与回复短信正文。
- **典型特征/关键词**：携号转网受阻、携转失败、无法携出、携号转网告知提醒、查询携转资格短信、获取携转授权码。
- **关键入参**：`手机号码`、`业务名称`（影响携转的在途协议/业务名称）、`创建时间`、`业务月份`、`extraInfo`（可选）。
- **与相近模板的区分点**：只要客户核心诉求是**携号转网（转网携出）受协议限制**，一律首选 **122**（切勿误选普通提前解约模板 110~114）。

### 123 活动办理争议类
- **适用场景**：客户对已办理的各类促销/优惠营销活动提出一般性办理核查诉求，需核实活动时间、活动内容、违约责任（客户承诺）以及确认与办理成功告知短信。
- **典型特征/关键词**：活动办理核实、参加优惠活动争议、营销案办理记录、活动有效期、客户承诺。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：结构精简，仅输出活动三要素与办理/确认/告知短信；若需附带网厅掌厅资费公示说明选 **128**；若客户明确投诉误导、宣传不符或承诺未兑现，分别选 **130 / 126 / 127**。

### 124 流量使用争议类
- **适用场景**：客户质疑套餐内流量消耗异常过快，或投诉当月流量达到阈值（如高速流量用尽降至 1Mbps、超 200GB 降至 128Kbps）后被触发达量降速/限速机制。
- **典型特征/关键词**：流量跑得快、流量虚跑、达量限速、上网速率变慢、降至1Mbps、128Kbps、触发限速机制、流量详单。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：聚焦**流量使用量核实与达量降速/限速规则**（无套外流量资费扣费分析）；若客户投诉的是超出套餐后被扣除“套餐外流量费/超额上网费”，必须选 **125**。

### 125 流量扣费争议处理模板
- **适用场景**：客户投诉超出套餐内国内流量或定向流量后产生套餐外上网流量扣费，需核查月度国内流量、定向流量额度、超出后计费标准（`标准资费`）及超额提醒机制。
- **典型特征/关键词**：流量扣费、套餐外上网费、超额流量费、定向流量超套、通用流量超出计费、消费提醒短信。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：聚焦**国内流量+定向流量额度与套外超额流量扣费**；若不涉及扣费仅投诉限速变慢选 **124**；若需同时核查整份月账单与跨月多类提醒列表（含 `账单` 入参）选 **119**。

### 126 营销宣传不符类
- **适用场景**：客户投诉办理业务或营销活动后，实际执行的资费、内容或限制条件与当时掌厅宣传页面、10086 热线外呼/呼入电话录音或营业厅受理单宣传不一致。
- **典型特征/关键词**：宣传不符、虚假宣传、与电话里说的不一样、宣传页面截图、电话录音沟通日期与时间段、受理单条款。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：独有按渠道举证宣传与告知一致性的尾段（热线渠道提取单据中的录音 `沟通日期` 与第 `时间段` 告知内容；掌厅核查办理页面标注）；若未涉及具体宣传物料/录音比对而仅笼统称被话术误导可选 **130**。

### 127 营销承诺不兑现类
- **适用场景**：客户反映参与营销活动时约定的返还话费、赠送流量/电子券/权益礼品或月租减免承诺未按期兑现到账，需核实原活动协议约定的活动内容与客户承诺条款。
- **典型特征/关键词**：承诺不兑现、赠费未到账、返话费没返、答应送的权益没有、优惠未生效。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：焦点在于**履约阶段承诺利益未兑现**；若焦点在于办理阶段宣传信息与实际协议不一致选 **126**；若因客户自身违约（如机卡分离）导致赠费停止选 **115**。

### 128 营销活动争议类
- **适用场景**：客户对名下营销活动产生常规争议（无到期涨价、宣传录音比对、赠费未兑现、误导话术等细分特征时的营销活动标准核查模板，含网厅掌厅公示说明）。
- **典型特征/关键词**：营销活动争议、优惠活动异议、营销案协议核查、活动内容与违约责任、产品公示。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：营销活动族的通用兜底模板（比 **123** 多了“本次问题涉及的产品已通过网厅和掌厅进行公示”段落）。

### 129 营销活动到期费用争议处理类
- **适用场景**：客户参与的营销活动期满后，因未申请取消或变更，按约恢复套餐原价或自动关闭从而引发账单费用变化争议。支持通过 `reminder-sms` 查询营销案到期前提醒短信。
- **典型特征/关键词**：营销活动到期扣费、活动期满涨价、营销案到期前提醒、恢复原价、套餐自动关闭。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`、`deadlineDate`（可选，营销活动到期日）。
- **与相近模板的区分点**：涵盖营销活动到期后“恢复原价/套餐自动关闭”两种结果并附“营销案到期前提醒”证明；若明确仅针对折扣优惠恢复套餐原价可对比 **105**。

### 130 营销活动误导办理类
- **适用场景**：客户承认办理了营销活动，但投诉业务人员在推销过程中存在诱导、夸大优惠力度、刻意隐瞒合约期或违约金等误导办理行为。
- **典型特征/关键词**：误导办理、诱导消费、欺骗办理、忽悠办活动、隐瞒合约期限制。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：针对“推销话术诱导/误导”；若有明确录音时间段需在正文中逐段指证已告知活动内容则选 **126**；若为普通套餐未告知标准资费则选 **103**。

### 131 过户业务受阻类
- **适用场景**：客户申请办理手机号码过户（变更机主）时受阻。模板调用 `pretty-number-info` 自动识别号码是否为靓号：属靓号则核查靓号等级、《靓号使用协议》未到期损失赔偿金或受让人重签靓号协议要求；非靓号则核查在途活动未到期支付违约金要求。
- **典型特征/关键词**：过户受阻、不让过户、号码转让他人、变更机主限制、靓号过户赔偿金、活动未到期过户。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：只要客户诉求是**办理过户受阻**（无论该号码是靓号还是普通号码），一律选 **131**；不涉及过户的靓号争议才选 **132**。

### 132 靓号协议争议类
- **适用场景**：客户针对靓号本身的靓号等级认定、最低保底消费金额、协议期限或《靓号使用协议》违约条款产生争议（不涉及过户）。调用 `pretty-number-info` 查询真实靓号等级与靓号活动名称。
- **典型特征/关键词**：靓号协议、靓号保底消费、靓号等级、吉祥号低消限制、《靓号使用协议》、取消靓号低消。
- **关键入参**：`手机号码`、`业务名称`、`创建时间`、`业务月份`。
- **与相近模板的区分点**：专用于非过户场景下的**靓号等级与《靓号使用协议》保底/合约期争议**；若客户是因为要把靓号过户给别人而受阻，应选 **131**。
