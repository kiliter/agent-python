# 模板路由（聊天推荐与自动路由共用指南）

本 Skill 供嵌入式聊天路由 Agent 推荐申告报告模板，以及上游接口未指定 `templateId` 时的自动路由阶段共同加载，不关联任何外部网关接口，也不绑定到任何填报模板。请采用 **两步按需路由**：先根据下方总则与分类索引锁定 1～2 个最相关的模板族，再调用 `load_skill(name="template-router", docs=["references/xxx.md"])` 按需加载对应细则，最后结合当前 `inputs`、`document` 与客户诉求匹配最贴合的在线模板（最多 3 个候选，自动路由按最高置信度直接执行）。

---

## 一、快速分流决策（先定族，再按需加载细则）

### （一）优先命中强特征专属入参

- 传入 `充值号码`、`充值时间`（或 `extraInfo` 含 `充值号码`）→ 直接加载 [话费充值与错充族](references/recharge.md)（106、107）。
- 传入 `账单`（如 `202610$202610`）→ 直接加载 [套餐变更、账单与流量族](references/plan-and-traffic.md)（优先 119）。
- 传入 `extraInfo` 含 `安装地址` → 加载 [宽带开户、续约与押金族](references/broadband.md)（优先 121）。
- 传入 `deadlineDate`（到期截止日）→ 重点排查到期/续约类模板（105/129 见 [业务办理与营销宣传族](references/order-and-marketing.md)，108/112 见 [合约解约、续约与违约金族](references/contract-and-penalty.md)，120 见 [宽带开户、续约与押金族](references/broadband.md)）。

## 二、置信度分级与推荐输出要求

- **推荐数量**：每次最多推荐 **3 个**在线模板，按匹配度从高到低排列；切勿推荐已下线或不存在的模板 ID。
- **置信度（`level`）标准**：
  - **高**：客户诉求、单据类型与入参特征完全吻合某一细分模板，边界清晰无歧义（通常首选为“高”，如有 1 个强相关备选可列为“中”）。
  - **中**：能锁定争议大类，但现有单据与入参未指明具体子场景（例如仅有活动受理单而无客户原话），可推荐同族最核心的 2～3 个模板并说明适用差异。
  - **低**：单据为空或信息极少、入参仅有手机号或模糊名称，只能提供通用兜底候选，并在回复中引导用户补充争议焦点或缺失入参。
